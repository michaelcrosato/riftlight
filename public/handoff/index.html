Pixel Engine handoff

Everything a coding agent needs to build a game on Pixel Engine outside its repository: the engine as one ES module, its guides, a starter game and a checker. The kit is rebuilt from main each time the site deploys, so this page always points at the current engine. manifest.json gives its version and build.

For an agent

  1. Download engine.zip and unzip it; everything lands in engine/: 
    curl -fLO https://riftlight.vercel.app/engine.zip && unzip engine.zip && cd engine
  2. Read README.md, then GUIDE.md whole. Search API.md; don't read it whole.
  3. Edit game.js into your game. Serve the folder over HTTP (npx serve .) and open index.html; ES modules don't load from file://.
  4. Run node check.mjs before you hand the game back: it plays the page in a browser and fails on any error. It needs Playwright (npm i -D playwright && npx playwright install chromium; GUIDE.md, section 8).

Can't reach this site, for example from a sandbox that only allows GitHub and package registries? Build the same kit from source: 

git clone --depth 1 https://github.com/michaelcrosato/riftlight && cd riftlight && npm ci && npm run bundle

Then copy bundle/pixel-engine/ to where your game will live and start at its README.md. Don't build the game inside bundle/: the next npm run bundle empties it.

What the kit holds

  • README.mdStart here: what is where and the order to read it.
  • GUIDE.mdThe manual: hosting, the mental model, a complete game, recipes, rules, common mistakes. Read it whole.
  • API.mdEvery export with its signature and doc. Search it.
  • ASSETS.md, LIBRARY.mdModels and textures as data; every built-in model and texture.
  • game.js, index.htmlThe starter game, a complete game to edit into yours. Play it.
  • check.mjsPlays a page in a real browser, saves screenshots, fails on any error; --sheets draws your models.
  • pixel-engine.js, pixel-engine.d.tsThe engine (three.js, Rapier and the built-in models inlined) and its types. Import it; never edit it or read it.
  • CHANGELOG.md, CREDITS.md, LICENSEWhat changed between versions, where everything came from, the MIT licence.
